# Cover Art

Place your podcast cover art here as `cover.jpg`.

## Requirements

- **Filename:** `cover.jpg`
- **Format:** JPEG (preferred) or PNG
- **Dimensions:** Minimum 1400×1400 pixels; maximum 3000×3000 pixels
- **Aspect ratio:** Square (1:1)
- **Color space:** RGB
- **File size:** Under 500 KB recommended

These requirements satisfy both Apple Podcasts and YouTube Podcasts standards.

## Placeholder

Until real cover art is added, the RSS feed will reference this path but the
image will return a 404. The feed is still valid — podcast apps will show a
default placeholder icon.

## Design Notes

The cover art should be recognizable at small sizes (as small as 55×55 px
in some podcast app list views). Use a clean, bold design with minimal text.
